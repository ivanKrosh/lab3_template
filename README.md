# Лабораторна робота №3 — шаблон рішення

Заготовка до лабораторної роботи №3 «Лінійні та розгалужені програми» курсу «Системне програмування»
(ВСП «Фаховий коледж інформаційних систем і технологій КНЕУ ім. Вадима Гетьмана»).

Усі проєкти вже налаштовано так, як вимагає методичка. **Не змінюйте налаштувань**, інакше вікно Disassembly не збігатиметься з наведеним у методичці.

## Склад рішення

| Проєкт | Файл | Крок | Що в ньому |
|---|---|---|---|
| `Step1_uptime` | `uptime.c` | 1 | лінійна програма: час роботи Windows |
| `Step2_branch` | `branch.c` | 2 | `if – else` у машинному коді; аргумент `-5` уже задано |
| `Step3_buffer` | `buffer.c` | 3 | програма з п'ятьма помилками — її треба виправити |
| `Step4_month` | `month.c` | 4 | `switch` і таблиця переходів; аргументи `2 2024` уже задано |
| `Step5_variant` | `variant.c` | 5 | заготовка програми за вашим варіантом |

## Як працювати

1. Відкрити `Lab3.slnx` у Visual Studio 2026 (*File → Open → Project/Solution*).
2. На панелі зверху вибрати **Debug** і **x64**.
3. Правою кнопкою на проєкті потрібного кроку → **Set as Startup Project**.
4. `F5` — запуск під налагоджувачем, `Ctrl+F5` — без нього.

**Аргументи командного рядка** змінюються в *Properties проєкту → Configuration Properties → Debugging → Command Arguments*.

**Лістинг асемблера** після збирання лежить у теці проєкту: `x64\Debug\<ім'я файлу>.asm` (для Release — `x64\Release\`).

## Що вже налаштовано

| Параметр (*Properties → C/C++*) | Значення | Навіщо |
|---|---|---|
| *General → Warning Level* | `/W4` | попередження про помилки в умовах |
| *General → Support Just My Code Debugging* | No (Debug) | без зайвого виклику на початку кожної функції |
| *General → Debug Information Format* | `/Zi` (Debug) | звичайний `.pdb` |
| *Code Generation → Basic Runtime Checks* | Default (Debug) | без додаткових перевірок стека в машинному коді |
| *Output Files → Assembler Output* | `/FA` | лістинг `.asm` для кроків 4 і 5 |
| *Optimization → Whole Program Optimization* | No (Release) | інакше в Release лістинг не створюється |
| *Command Line → Additional Options* | `/utf-8` | вихідні файли збережено в UTF-8 |

## Відомі граблі

**Попередження `C4706` у `Step3_buffer`.** Воно навмисне — це одна з п'яти помилок кроку 3. Рішення збирається успішно.

**Консоль закривається одразу після `F5`.** Поставте точку зупину на `return` або вимкніть *Tools → Options → Debugging → General → Automatically close the console when debugging stops*.

**Рішення не відкривається.** Файл збережено в новому форматі `.slnx`. Оновіть Visual Studio або відкрийте потрібний `.vcxproj` напряму.
